# MeteorAgent 桌面内测版 · Windows

此包适用于 Windows 10 或 Windows 11（x64）。双击 `Setup.exe` 安装。完成后可以用桌面或开始菜单里的「MeteorAgent Beta」打开独立窗口。安装包已经包含运行环境，打开后用流星 API 账号登录。

这是供小范围试用的未签名安装包。可以用附带的 `SHA256SUMS` 核对安装文件。如果 Windows 提示无法验证发布者，请先确认来源。某些受管理的电脑可能不允许安装此类应用。

如果之前用过网页版，桌面版会读取电脑上已有的账号、会话和插件。请先等旧版任务结束，再切换到桌面版。同一会话请在一个版本里操作。

更新时请退出「MeteorAgent Beta」，然后运行新版安装程序。退出后也可以在文件资源管理器中手动移除 `%LOCALAPPDATA%\Programs\MeteorAgent Beta` 和对应快捷方式。账号和会话保存在应用安装目录以外。
