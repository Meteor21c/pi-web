# MeteorAgent 桌面内测版 · Windows

此包适用于 Windows 10 或 Windows 11（x64）。双击 `Setup.exe`，在「选择安装位置」页面接受默认路径，或浏览选择一个可写入的应用文件夹。完成后可以用桌面或开始菜单里的「MeteorAgent Beta」打开独立窗口。安装包已经包含运行环境，打开后用流星 API 账号登录。

这是供小范围试用的未签名安装包。可以用附带的 `SHA256SUMS` 核对安装文件。如果 Windows 提示无法验证发布者，请先确认来源。某些受管理的电脑可能不允许安装此类应用。

如果之前用过网页版，桌面版会读取电脑上已有的账号、会话和插件。请先等旧版任务结束，再切换到桌面版。同一会话请在一个版本里操作。

更新时请退出「MeteorAgent Beta」，然后运行新版安装程序。安装程序会预填上次成功安装的位置。选择其他位置会安装额外的副本，并把桌面和开始菜单的快捷方式指向新位置。退出应用后，可在文件资源管理器中手动移除所选安装文件夹及其快捷方式。账号、会话和插件保存在应用安装目录以外。
