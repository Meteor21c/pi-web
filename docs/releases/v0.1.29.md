## 本次更新

- Windows 的「重启 Magent」会重新启动后台服务，浏览器会在服务恢复后自动刷新。项目目录、用本机应用打开文件和在文件夹中显示均使用 Windows Shell。
- Windows 启动器改名为「【点我启动】MeteorAgent」。首次成功启动后会创建带金丝熊图标的桌面快捷方式。
- 聊天框下方可直接选择子代理模式。旧会话缺少工具时，可确认仅为当前会话启用完整工具。批准策略可单独切换，运行中选择会从下一条任务生效。
- 会话顶部新增「重新加载会话」，用于应用插件和技能设置。重载会保留会话历史和输入草稿。
- 电脑操作在普通会话中默认开启。可在顶部「插件」关闭当前会话，之前明确关闭的设置继续有效。
- 思考强度滑块跟手移动，松手后平滑吸附到档位。拖动时会显示短暂的主题色粒子，系统开启减少动态效果时会省略粒子。

## 安装

已有用户可从左下角账户菜单检查更新。Windows 用户如果想使用改名后的启动文件和桌面快捷方式，可以下载新版 Windows 启动器并完整解压。首次安装需 Node.js 22.19.0 或以上版本。
