# MeteorAgent v0.1.30

- 侧栏支持命名项目、多个可访问文件夹和默认工作目录。旧会话可以移动到项目，随手提问可以使用独立聊天。
- 从回复创建分支时，会话默认按「（1）」「（2）」编号。聊天内的分隔线标记新分支开始的位置。
- 内置电脑操作在普通会话中由全局插件设置管理。会话的工具限制、电脑操作批准策略和操作系统权限继续生效。
- 下载页提供独立的桌面客户端和 Web 版入口。桌面客户端支持 macOS（Apple Silicon）和 Windows（x64），安装包自带运行环境。
- Web 版和桌面客户端分别查询各自的最新稳定版本。Web 启动器版可在应用内更新并重启。桌面客户端会提供当前平台的最新安装包，下载完成后退出应用并覆盖安装。
