# MeteorAgent v0.1.19

## 更新内容

- 思考、命令和工具详情默认折叠，阶段更新、图片和最终结果直接显示。
- 聊天框可自动启用、关闭或要求使用子代理。子代理启动后显示任务状态，点开可在右侧查看进度。
- 新增和同步模型会读取可用能力信息，支持仅自动推理预设。修复 DeepSeek V4.1 Flash 的模型能力匹配。
- 模型上下文窗口可自定义，留空使用默认值。已同步首阶计费上限的分组会按该上限限制实际窗口。
- 对话结束后汇总本轮确认修改、创建和生成的文件，点击即可预览。
- 消息和输入框共享阅读宽度，两侧边距随窗口宽度调整。

在左下角账户菜单选择「检查更新」即可安装。模型能力可在「设置 → 模型」重新同步当前账户分组。
