# MeteorAgent v0.1.17

## 新功能

- 新增提示词预设：在设置中创建和编辑多个常用预设，在顶部“助手规则”中为新对话选择。
- 输入框下方新增自动、计划、目标模式。
- 计划模式只开放文件读取和搜索，用于分析需求与制定计划；目标模式在单次任务中推进并核对结果。
- 新对话首次发送后保存提示词和模式快照，后续编辑或删除预设不影响已有对话。

## 修复与优化

- 修复 macOS 多个安装位置并存时，更新器误停或重启另一安装实例的问题。
- 更新器在安装包之外运行，避免升级替换程序后回滚出现工作目录丢失。

- 更新 Pi 运行时至 0.87.1，纳入图片输入、上下文压缩和扩展上下文处理的官方修复。
- 合并 pi-web 官方快捷键修复，macOS 可使用 Ctrl+Option+N 新建对话，并保留 Windows AltGr 输入。
- 保存模型配置时保留用户设置的符号链接，失效链接会拒绝写入。
- 更新网页与网络库等依赖，修复新披露的安全漏洞。

## 使用说明

模式与预设可在新对话首次发送前调整，开始后固定。计划模式不改变已安装插件本身的系统权限；目标模式不会定时唤醒或无限重试。

已有用户可以在账户菜单中点击“检查更新”，确认后自动下载、安装和重启。更新保留账号、会话、插件和项目文件。
