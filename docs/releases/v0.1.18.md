# MeteorAgent v0.1.18

## 更新内容

- 助手规则预设现在会整体替换系统提示词，不再把自定义内容追加在 MeteorAgent 默认提示词之后。
- 可编辑 MeteorAgent 默认系统提示词，也可以创建多套完整提示词预设用于新对话。
- 新对话首次发送时固定提示词快照；已开始的对话保留原提示词。
- 自动、计划、目标模式继续独立生效，提示词不会改变界面控制的工具权限。
- 修复繁体中文界面缺少提示词预设词条的问题。

## 升级

稳定版用户会在应用检查更新时收到 v0.1.18 提示。确认后，应用下载并校验更新包，再安装和重启；账号、会话、插件和项目文件保留。
