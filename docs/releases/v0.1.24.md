## 本次更新

- 模型的「自动」上下文优先采用流星 API 同步的首阶计费窗口，其次按精确模型匹配 models.dev 或 Pi 内置目录。手动填写的窗口优先应用，也会反映在会话右上角。
- 运行时展示阶段进度和耗时。完成后，中间输出与命令以动画收进「操作记录」，最后的结果单独显示。
- 高推理强度下，「自动」会请求主模型安排子智能体。子智能体的状态在主对话中显示，点名称可在侧栏查看过程和结果。
- 修正支持自适应思考的 Claude 模型的请求格式。模型不支持当前推理强度时，会尝试下一档可用强度，必要时回到「自动」。
- 完成或取消的目标可以收起，之后仍可从目标入口查看。

## 安装

已有用户可在应用内检查更新。首次安装请下载对应平台的启动器，需要 Node.js 22.19.0 或以上版本。
